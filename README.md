AI-Assisted Pneumonia Detection

Problem:
Automated detection of Pneumonia from Chest X-rays to assist doctors and reduce diagnostic delays.

Solution:
A deep learning system using a pretrained ResNet CNN to classify X-rays and Grad-CAM to explain predictions.

Tech Stack:
- PyTorch
- Grad-CAM
- FastAPI
- Streamlit

Key Features
- High recall-focused classification
- Explainable heatmaps
- Doctor-friendly UI

Roadmap
- Train CNN on labeled X-ray data
- Optimize for recall
- Integrate Grad-CAM
- Deploy UI for real-time inference
